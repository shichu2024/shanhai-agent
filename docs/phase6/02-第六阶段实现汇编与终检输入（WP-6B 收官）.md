## 五、本批（6-4）随批实测发现与修复

P3-① 收口实测（tsx 形态 CLI approve）暴露两处既有资源释放缺陷，随批最小修复：

1. **withTimeout 超时定时器不清理**（`src/modules/toolExecutor.ts`）：竞速落定后定时器仍被事件循环持有跑满 toolTimeoutMs（30s），CLI 进程命令完成后延迟退出。修复=落定后 `clearTimeout`（`.finally`），竞速语义不变。
2. **CLI 命令结束不释放 Runtime**（`src/cli.ts`）：external MCP bridge 按需 spawn 的子进程句柄使进程不退出（portal 路径不受影响——SIGINT/SIGTERM 释放既有）。修复=命令尾部 `rt.close()`。
3. **冒烟脚本 undici 连接池失效**（`scripts/smoke-portal.mjs`）：长 `spawnSync`（tsx 形态 ~4s）阻塞后，全局 fetch 连接池中 keep-alive socket 失效，复用即 ECONNRESET（Windows 实测）。修复=api() 改 node:http 一次性连接（`agent:false`）。
