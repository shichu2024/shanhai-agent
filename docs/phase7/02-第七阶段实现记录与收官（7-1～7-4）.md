### 2.3 占位收尾

agents 族「建设中」占位随本批移除——至此全站（三一级导航 + 观测二级 + Agent 族 + not-found）无占位页。

### 2.4 P3-2 smoke 遗留 portal 子进程修复（7-1 备案处置）

根因：tsx 形态入口链 `npx-cli → tsx → cli` 为进程树，原 `portal.kill()`（SIGTERM/TerminateProcess）只终止直接子进程，孙进程遗留（端口占用、进程泄漏）。修复：`killTree`（Windows `taskkill /pid <pid> /T /F` 整树；POSIX SIGTERM）+ `waitForExit`（exit 事件确认，超时如实 FAIL 留档）。冒烟新增 check「portal 进程树退出无遗留（P3-2）」，双形态 22/22 实证通过。
