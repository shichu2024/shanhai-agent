## 1. 分类总表（class / subClass 两级，封闭集）

> 记法：`Class(SubClass)`。class 7 类；Planning 类**不设**（第一阶段无 Planner 模块，模型规划失败归 Model 类；第二阶段引入编排层时再增补——显式记录，不留沉默空洞）。

| Class | SubClass | 触发场景 | 计入契约失败率 | 出现层级 |
|---|---|---|---|---|
| `Input` | `contract_mismatch` | 任务时**防御性复验**发现输入不符 Input Contract（创建入口的结构性不符已在落库前被拒、走 RejectedRequest；本子类仅捕获「创建时合法、复验时不合法」的漂移窗口——A3 §3.1 分工表 ③） | 否 | 任务终局（Created→Failed） |
| `Spec` | `defensive_revalidation_failed` | 任务时防御性校验失败（悬空引用/哈希不符/被篡改） | 否 | 任务终局（Created→Failed） |
| `Model` | `provider_error` | Provider API 错误（非 Schema 拒绝、非限流类） | 否 | attempt / 终局（耗尽后） |
| `Model` | `provider_infra`（= infra_failure） | Provider 限流、网络中断、服务不可用 | **否（显式排除）** | attempt / 终局 |
| `Model` | `call_timeout` | 单次调用超时（A2 `callTimeoutMs`） | 否 | attempt |
| `Model` | `unparseable_output` | 输出不可 JSON 解析（L1 校验失败） | **是** | attempt / 终局 |
| `Model` | `schema_violation` | L2 校验失败：结构/必填/类型不符 | **是** | attempt / 终局 |
| `Model` | `enum_violation` | 枚举取值越界 | **是** | attempt / 终局 |
| `Model` | `format_violation` | format 白名单校验失败 | **是** | attempt / 终局 |
| `Model` | `truncation` | 输出截断（finish_reason/长度上限） | **是** | attempt / 终局 |
| `Model` | `provider_rejected_schema` | **Schema 被 Provider 拒绝**（ND-2：非模型输出问题） | **否（显式排除，类比 infra_failure）** | attempt（策略 A 下） |
| `Tool` | `execution_failed` | 工具执行自身错误 | 否 | attempt / 终局（耗尽后） |
| `Tool` | `timeout` | 工具执行超时 | 否 | attempt |
| `Tool` | `invalid_params` | 工具参数结构不合法（非 L2 策略拦截） | 否 | attempt |
| `Policy` | `PolicyBlocked` | 连续拦截达 `maxConsecutiveDenials`（归因不漂移锚点） | 否 | 任务终局 |
| `Runtime` | `BudgetExceeded` | `maxModelCalls` / `maxTokens` 超限（C3-② 锚点） | 否 | 任务终局 |
| `Runtime` | `TaskTimeout` | 任务级超时（A2 `taskTimeoutMs` 启用时） | 否 | 任务终局 |
| `Runtime` | `CrashRecovery` | 重启发现非终态遗留（A3 §6） | 否 | 恢复路径 |
| `Runtime` | `internal_error` | Runtime 自身缺陷（不应发生路径） | 否 | 任意 |
| `Output` | `ContractViolation` | 最终输出不符 outputContract（含未声明 allowEmpty 而输出空） | **是**（任务级首判） | 任务终局 |

**「计入契约失败率」口径（C2 冻结）：** 仅标「是」的子类进入 C2 分母/分子；`provider_infra` 与 `provider_rejected_schema` **排除出契约失败率**并单独计数；「provider 通过但本地校验失败」样本单独计数（Provider 语义不一致的直接度量，假设 #4 实验副产品）。

## 3. 归因映射表（迁移/事件 → 分类）

| 来源（A3 迁移 / A2 流程） | 分类 |
|---|---|
| Created→Failed（输入复验失败） | `Input(contract_mismatch)`（仅经 A3 §3.1 分工表 ③ 可达） |
| Created→Failed（防御性校验） | `Spec(defensive_revalidation_failed)` |
| Running→Running（attempt 失败） | Model/Tool 对应子类（attempt 级，不计任务失败） |
| Running→Failed ① attempt 耗尽 | 末次 attempt 的子类升级为终局 |
| Running→Failed ② 任务级超时 | `Runtime(TaskTimeout)` |
| Running→Failed ③ 预算超限 | `Runtime(BudgetExceeded)`（不得记为 Model 或 Policy） |
| Running→Failed ④ 连续拦截超限 | `Policy(PolicyBlocked)`（不得记为 BudgetExceeded——归因不漂移） |
| Running→Failed ⑤ 输出契约失败 | `Output(ContractViolation)` 或末次 attempt 的契约子类 |
| Queued/Running 遗留→Failed | `Runtime(CrashRecovery)` |

**归因不漂移规则（冻结）：** 每条终局失败归因唯一且由触发路径机械决定（上表左列），禁止实现层「就近归类」或「兜底归类」；`internal_error` 仅限真正的不可分类路径，出现即缺陷信号。

## 4. C2 报告聚合口径（P1-3 修订：分母定义更正）

1. **分母 = 全部尝试样本 −（`provider_infra` + `provider_rejected_schema` + 判例排除）**——成功样本**在分母内**（初稿「标是子类的尝试样本」把成功样本排除在分母外，数学上不成立，本条更正）；**分子 = attempt 1 即契约通过的样本数**（首次通过率主指标）；
2. 被排除的三类不进分母，单独计数列示；「provider 通过但本地校验失败」样本单独计数（Provider 语义不一致度量）；
3. 落库前拒绝（A3 §3.1 分工表 ①②）**不产生尝试样本**（无 Trace、无 Task），不进入任何口径，仅审计流留痕；
4. 报告维度：按 Spec 分层（S1/S2/S3 禁止只报合计）+ Wilson 95% CI + 失败分布直方（按 subClass）；
5. 数据源 = FailureRecord + Trace（实验数据走 TraceRecorder 标准通道，11 号 §2.2）；
6. `Runtime(BudgetExceeded)` 终局附调用构成明细（D-2 附条件，结构见 A2 §7），使「预算被 infra 消耗」可辨。
