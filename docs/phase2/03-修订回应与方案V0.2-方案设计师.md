## 2. 无不接受项的说明

本修订无不接受条目。两点说明：
1. P0-1 的两个修复选项中选 (b) 而非 (a)——这不是「不接受 (a)」，是在反方给出的两可行选项中的选型，选型理由（24h 进程存活是落地硬墙）即反方自己的七维度结论；
2. P2-3「部分接受」：拒绝的是「输出与记忆内容相关」这一判定路径（不可机械可靠），采纳的是「可判近似 + 恢复边」的等效安全效果。**承担的风险：**注入列表逐条计数的粒度比「归因到哪条」粗——一次失败会把本次注入的全部记忆各记一次反例。**为何可接受：**恢复边使误伤自愈（成本 = 每条记忆多需一次印证），而引入相关性判定器的成本与不可靠性更高。**验证措施：**批次三 DoD-② 已含 degraded 触发 + 恢复边单测，误伤场景（多记忆注入 + 无关失败 + 后续印证恢复）纳入用例。
